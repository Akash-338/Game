# Redis Provider Evidence

The recommended temporary coordination provider is **Upstash Redis Free**. Its official pricing page lists the Free plan at **$0/month**, with 256 MB of data and 10 GB of bandwidth; it also states a 500K-command monthly allowance. The full pricing and limit details remain governed by Upstash’s published page.[1]

For a durable free database, create it from the Upstash Console and keep it in the region nearest the persistent backend. Upstash’s no-signup endpoint is useful only for temporary experiments because an unclaimed database is deleted after three days; it is not appropriate for the Word Impostor production backend.[1] [2]

The backend should hold `UPSTASH_REDIS_REST_URL` and `UPSTASH_REDIS_REST_TOKEN` as server-side secrets. Upstash documents that the `@upstash/redis` client can load these from environment variables; neither value belongs in browser code.[3]

## Realtime adapter requirements

Socket.IO’s Redis adapter forwards cross-instance packets through Redis Pub/Sub and requires Redis to stay private, authenticated, and TLS-protected.[4] The official adapter guide notes potential subscription-recovery concerns with `redis` and presents `ioredis` as an alternative.[4] Upstash documents TLS as mandatory and provides a Node.js `ioredis` connection using a `rediss://` URL.[5]

Therefore the future persistent backend will use a server-only `UPSTASH_REDIS_URL` (the TLS endpoint generated by the Upstash database page), `ioredis`, and `@socket.io/redis-adapter`. Browser code will never receive this URL, password, REST token, or database endpoint.
